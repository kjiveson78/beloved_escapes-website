## Separation rule

Beloved Escapes is the travel-agency and holiday-booking brand. It must remain operationally and compliantly separate from LuvToTravel, which presents an independent business-opportunity journey.

Do not copy LuvToTravel recruitment, network-marketing, PlanNet opportunity or income-related content into this repository. Likewise, Beloved Escapes booking activity, customer travel data and InteleTravel agency content must not be introduced into the LuvToTravel website repository.

## Dormant-repository policy

Until Kevin explicitly authorises development:

1. Do not add application code.
2. Do not add deployment workflows.
3. Do not connect hosting, domains, forms, analytics or customer systems.
4. Do not store customer, booking or personal information here.
5. Keep the repository private.
6. Use issues or planning documents only when future development is approved.

This README intentionally acts as the dormant marker. No website build has been transferred into this repository.
